# mentoor-social
Piezas y recursos públicos para las redes de Mentoor (@mentoor.cl).

- `brand/` — kit de marca **oficial** (extraído del código de la app) + uso en redes.
- `templates/` — plantillas HTML que se renderizan a PNG (carruseles y posts).
- `posts/` — piezas listas, cada una con su imagen y `caption.txt`.

Este repositorio es **público**: no subir claves, datos reales de estudiantes ni nada confidencial.
